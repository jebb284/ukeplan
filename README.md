# Ukeplan – Maskin og Teknikk

Internal web app for the staff at Maskin og Teknikk: weekly plan, clock in/out and enquiries from the website.
Installable on iPhone/Android from the browser ("Legg til på Hjem-skjerm").

- Data, logins and access rules live in Supabase. Nothing is readable without being on the staff list.
- `config.js` holds the project URL and the *publishable* key, which is meant to be public.
